# 已知缺口与来源冲突

中文 | [English](known-limitations.en.md)

这是现有资料和固定源码的状态记录。本次工作是归档和说明，不包含对原控制程序的功能重写。

| 范围 | 已发现情况 | 对复现的影响 / 后续所需证据 |
| --- | --- | --- |
| V4 树莓派 | 使用说明给出 `joystick_control` 目录和自启记录，没有服务端源文件 | 需从原机补充代码、服务定义、串口设置与依赖；历史图片示例不能替代 |
| V4-pro PC 程序 | Orin 文档使用配套 Windows 手柄程序，未给出可确认的源码仓库或附件 | 需补充与 UDP41字节格式配套的 PC 程序；V4 TCP 客户端不兼容 |
| V4 固件板卡 | 系统资料称 C 板，当前工程明确 STM32F407IGHx | 核对实际PCB/芯片/引脚与烧写目标，不凭文件名声明通用兼容 |
| V4 IMU | 当前 H30 参与反馈，但启动仍检查 BMI088 | 单独接 H30 是否能够完成初始化需核验 |
| V4 UART | 只检查接收长度≥2，部分指令需4字节；共享DMA缓存无快照 | 存在短帧/缓存残留/覆盖风险；串口桥需按实际边界配套 |
| V4 控制语义 | `02 10` 翻转闭环，`02 20` 空实现；关闭闭环后仍输出1590 μs | 不能把重复切换当幂等启动，也不能将其当物理停机 |
| V4 超时与总线 | 看门狗未启用，I²C忙等无超时，标定写Flash被注释 | 不声称失联自动停桨或校准重启持久化 |
| V4 深度 | 当前计算保留压差代理；注释中的cm与运算链未形成严格单位保证 | 需测量并标定实际单位、零偏及换算 |
| V4 数量/电流 | 配件表舵机2、继电器30 A；旧电路文档舵机4、继电器120 A | BOM保留冲突；以实物器件、机构和负载核对，未替用户定型 |
| V4-pro PWM供电 | 制作文字8.4 V，简化图舵机5 V；图中主供电24 V | 不能把三者混成一条供电；检查负载规格、板卡跳线和电平 |
| V4-pro 分支绑定 | pro1/pro2有电机、IMU和压力融合差异，制造文档未指明配哪台 | 保留两个版本和补丁，不给实物自动分配分支 |
| V4-pro 电调 | 当前源码为DSHOT双向3D模式，制作文字未给完整电调固件/参数 | 不能将V4的50 Hz PWM设置套用；需核对电调支持及实际配置 |
| V4-pro 构建 | 上游MDK工程未列入TaskSUB.cpp，CMake依赖Windows Arm Compiler 6 | 保留并说明构建入口；本次未安装专有工具链，也未宣称工程已构建成功 |
| Jetson 脚本 | 原生struct字节序；串口打开失败不自动恢复；未实现断流自动停机 | 协议格式静态匹配不等于运行保障 |
| 视频脚本 | raw分支缺少管道连接符；CPU回退仍接NVMM；超时异常类型问题 | 原件留存；对应分支需要修复和Jetson/摄像头验证 |
| 自启动 | 原附件有个人路径、chmod777、按进程名清理 | 原件仅作追溯；提供独立systemd模板供按现场环境配置 |
| 历史图像demo | 服务端发送长度/对象与pickle编码不匹配，若干脚本不完整 | 仅收为历史研发资料，不列为当前系统依赖 |
| 许可 | 部分程序、机械和文档未附明确再分发许可 | 当前保持私有；公开前确认权利归属与许可范围 |
| 性能指标 | 未提供可复核的全套耐压、续航、速度和闭环性能报告 | README不填写推测指标；10 m传感器量程不是潜器额定潜深 |

详细源码依据见 [V4 固件](firmware-v4.md)、[Pro 导入](../firmware/v4-pro/IMPORT.md)、[V4 PC](../software/v4-topside/IMPORT.md) 和 [Jetson](../software/v4-pro-jetson/README.md)。
