# V4 与 V4-pro 差异

中文 | [English](variants.en.md)

这里的 **V4** 指《比赛细节与V4设计》《V4使用说明》中的树莓派 / RM-C 系统，控制代码按指定的 IWIN-FINS `V4-ly` 固定。**V4-pro** 指《V4-PRO制作文档汇总（RM-A主控）》及其 Orin 配置资料中的系统。FineSUB `v4pro1` / `V4pro2` 是 Pro 内部两个配置版本，不能拿来代替 V4 / V4-pro 对照。

## 结构与电气

| 部分 | V4 | V4-pro | 复用时的区别 |
| --- | --- | --- | --- |
| 框架与舱内板架 | 2025-05-23 V4 模型，C 板 / 树莓派布局 | 独立 V4pro 模型，A 板 / Jetson / 电调布局 | 两套同名零件不能因名字相同就互换；尺寸以各自 CAD 为准 |
| 后续机械件 | 2025-07-10 单目相机支架；另有机械爪设计附件 | 双舵机相机云台、补光灯固定件 | 机械爪附件是设计资料，不代表已集成控制 |
| 舱内计算机 | 树莓派 4B | 制作清单写 NANO；引用配置说明明确 Orin Nano / NX | 串口设备名、载板引脚和环境不同 |
| 主控 | 系统文档 RM-C；指定工程目标 STM32F407IGHx | RM-A / STM32F427 | 按实际板卡、芯片和工程复核，不交换烧录文件 |
| 推进器数量 | 8 | 8，4 正桨 + 4 反桨 | 相同数量不代表相同通道/方向 |
| 推进器驱动 | 文档三线：电源正、负、PWM；PCA9685 0–7 输出 | 不带电调推进器 + 2 块四合一电调；三根电机相线 | **三芯接口语义不同**，不能按 V4 的红黑黄电源定义接 Pro 相线 |
| 执行器信号 | I²C 扩展板通道 4 → PCA9685，50 Hz PWM | 当前FineSUB推进器使用DSHOT双向3D模式；舵机/灯具使用PWM。制作说明标Z–S为推进器接头 | 板上字母、DSHOT ID、源码索引与俯视编号要建立对应；电调须支持并配置所用协议 |
| 水压计 | 4；配件表不锈钢、10 m 量程，线长 65 cm | 4；316L、10 m 量程，线长 70 cm | 量程不能作为整机耐压等级；每台独立标定 |
| 舵机 | 采购表 2，旧电路文档和固件 4 路 | 制作清单 2，A 板 C / D 接口 | V4 数量存在来源冲突，按实际机构确认 |
| 补光灯 | 给定 V4 清单未形成与 Pro 对等的灯配置 | 2，制作说明 A / B，100°光束角 | 不把 Pro 接口表直接套用到 V4 |
| 主供电 | 4S 电池，旧文档记 10000 mAh / 25C | 接线图标定制 24 V 电源 | Pro 电池确切容量与电芯串数未给出 |
| 继电器 | 配件表 30 A；旧电路文档 120 A | 定制电池、旋钮开关、分电板方案 | V4 两个值存在冲突，不能选一个当已验证额定值 |
| 舵机/PWM 供电 | 旧图有 5 V 路径 | 简化图舵机标 5 V，制作文字要求可调 PWM 供电 8.4 V | Pro 来源矛盾；先核实负载、电平和板卡跳线，不能把8.4 V接到逻辑输入 |
| 水面通信 | 以太网系缆 | 以太网，制作清单另有一对电力载波模块 | 首次联调按 Orin 文档可先用直连网线定位问题 |

详细加工、连接器线序和装配步骤见 [V4 硬件](hardware-v4.md)、[V4-pro 硬件](hardware-v4-pro.md) 与 [BOM](bom.md)。

## 控制与通信

| 部分 | V4 / IWIN-FINS V4-ly | V4-pro / FineSUB |
| --- | --- | --- |
| 固件组织 | 裸机主循环 + 中断，设备指针表 | FineSUB 组件、设备与任务框架 |
| PC→舱内计算机 | TCP 5000，发送设备命令字节 | UDP 12345，41 字节原始手柄数据 |
| 命令 UART | UART6，115200，8E1 | UART3，115200，8N1 |
| 串口帧 | 设备地址、命令、可选负载；无统一帧头/CRC/长度 | `AA` + 25 字节负载 + 2 字节 Modbus CRC16，共28字节 |
| 数据含义 | 各设备单独指令，16位负载小端；`02 10` 翻转闭环 | 5个float、3个uint8、2个int8；来自手柄整体状态 |
| IMU 串口 | USART1，921600，8N1 | UART7，921600，8N1 |
| 姿态轴向 | H30 roll加π、pitch/yaw取反；初始化仍检查BMI088 | Pro1/Pro2 的 `rotationOffset` 不同 |
| 压力融合 | 当前源码取四路深度代理平均，物理单位需标定 | Pro1取测点1/3平均，Pro2取测点3（源码数组索引） |
| 执行器映射 | V40固定数组、PCA9685通道、1590 μs初值 | FineSUB DSHOT ID与3D双向模式，Pro1/Pro2另有端口与符号差异 |
| PC客户端配套 | 收录 `rov-v4-wired-joystick` | 所给资料未提供可确认的配套Windows源码 |
| 舱内转发程序 | 原机 `joystick_control` 未提供源码 | 收录 V5StreamerNX.py 和 GStreamerTest.py |

V4 固件的 `Robot_Version` 枚举 V30/V31/V32/V33/V40 是历史配置；没有名为 V4-pro 的分支。仅改成 V40 或复制 Pro 的分配矩阵不能完成跨平台移植。

## Pro1 与 Pro2 的进一步区别

本仓库保留 `v4pro1` 作为便于比较的源码基准，并提供 `V4pro2` 精确补丁；**没有证据将用户当前某一台实物自动绑定到其中某个分支**。两者差异包括 IMU 方向、压力测点选择、电机端口与推力符号、偏航输入比例和死区/限幅。

应用方式、精确源码差异及固定提交见 [V4-pro 导入记录](../firmware/v4-pro/IMPORT.md) 和 [Pro 配置说明](../firmware/v4-pro/variants/README.md)。这些属于具体潜器标定配置，不应只挑其中一个参数复制。
